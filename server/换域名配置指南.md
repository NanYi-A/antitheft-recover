# 防盗找回 App · 换域名配置指南

> 场景：换了一个新域名（如 `relay.newdomain.com`），**IP 可能不变**（同服务器）。
> 适用：2026-08-16 之后的架构（HTTPS/WSS 已启用）。

## 0. 核心结论（先看，和换服务器最大的区别）

| 改动点 | 换域名要不要动 | 说明 |
|---|---|---|
| **安卓端 `Constants.kt`** | **必须改 + 重打包 APK** | 域名硬编码在 `RELAY_BASE`，服务端地址写死在 APK 里，不重打包旧 APK 永远连旧域名 |
| **WS 地址（wss）** | 不用单独改 | `RealtimeService` 从 `RELAY_BASE` 自动派生 `ws→wss`，改了 `RELAY_BASE` 自动跟着变 |
| **服务端 Python 代码** | **一行都不用改** | 域名只在宝塔 Nginx 反代层，代码里没有任何域名硬编码 |
| **数据库 / 历史数据** | 不用动 | 同服务器同目录，域名无关 |
| **宝塔站点 / 证书 / 反代** | 必须新建（给新域名） | 新域名要新证书、新反代配置 |
| **DNS** | 新域名 A 记录指向服务器 IP | IP 不变的话不用改 IP |

> ⚠️ **最容易翻车的一点**：换域名忘了重打包 APK。结果服务端新域名配好了，但手机里的 APK 还在连旧域名，永远连不上。所以安卓端改动是强制项。

---

## 1. 安卓端（必须，优先级最高）

### 1.1 改代码
文件：`<project-root>\app\app\src\main\java\com\example\antitheft\Constants.kt`

```kotlin
// 改前
const val RELAY_BASE = "https://relay.example.com"
// 改后（举例）
const val RELAY_BASE = "https://relay.newdomain.com"
```

- 如果新域名带非标端口（如 `:8443`），就写成 `"https://relay.newdomain.com:8443"`。
- 不要加末尾斜杠。
- `usesCleartextTraffic` 已设 `false`（禁明文），保持即可。

### 1.2 重打包 APK
```bash
# 在 <project-root>\app 目录下，用已验证的 gradle 二进制（绕开 cmd.exe 限制）
set JAVA_HOME=D:\AndroidStudio\jbr
set GRADLE_USER_HOME=D:\.gradle
set ANDROID_HOME=C:\Users\<you>\AppData\Local\Android\Sdk
gradle assembleDebug
```
产物：`<project-root>\app\app\build\outputs\apk\debug\app-debug.apk`

### 1.3 装到手机
```bash
adb install -r <project-root>\app\app\build\outputs\apk\debug\app-debug.apk
```
或传手机直接安装。装后设置页确认服务器地址显示新域名。

## 2. 服务端（代码不改，只动宝塔）

### 2.1 宝塔加新域名站点
- 网站 → 添加站点，域名填**新域名**（如 `relay.newdomain.com`），纯静态。
- 根目录可用空目录（不要指向 `ai-voice-relay` 源码目录）。

### 2.2 SSL 证书
- 站点 → SSL → Let's Encrypt → 勾选**新域名** → 申请。
- 域名已备案：HTTP-01（默认）。
- 域名**未备案**：用 **DNS 验证（DNS-01）** 填阿里云 AccessKey。
- 开启「**强制 HTTPS**」。

### 2.3 反向代理（关键）
- 目标 URL：`http://127.0.0.1:8001`，发送域名 `$host`。
- 配置文件确认含：
  ```nginx
  proxy_http_version 1.1;
  proxy_set_header Upgrade $http_upgrade;
  proxy_set_header Connection $connection_upgrade;
  proxy_read_timeout 3600s;
  proxy_send_timeout 3600s;
  proxy_no_cache 1;
  proxy_cache_bypass 1;
  ```
- 缺 `Upgrade/Connection` → WS 断；缺 `proxy_no_cache` → 接口被缓存读旧数据。

### 2.4 放行端口
- 宝塔「安全」+ 阿里云安全组 → 放行 **443**。

### 2.5 不用动
- `anti_theft.py` / `main.py` 不用改。
- `anti_theft.db` / 照片 / 相册目录不用动（同服务器同目录）。
- 进程守护 `ai-voice-relay` 不用重启（它只监听 `127.0.0.1:8001`，跟域名无关）。

---

## 3. DNS

新域名控制台（阿里云/腾讯云/DNSPod）：
- `relay.newdomain.com` 的 **A 记录**指向**服务器公网 IP**（IP 不变就填原来的 IP）。
- 等 TTL 生效。

---

## 4. 过渡方案（推荐，避免旧 APK 立即失联）

如果你希望**旧 APK（连旧域名）还能继续用一段时间**，直到全部换成新 APK：
- 旧域名的宝塔站点**保留不删**，反代也指向同一个 `127.0.0.1:8001`。
- 这样新旧域名同时反代到同一后端，新旧 APK 都能用。
- 旧证书到期前记得续（或旧域名准备弃用时再删站点）。

> 旧域名如果**准备彻底弃用**：删旧站点、删旧 DNS 记录即可，不影响新域名。

## 5. 验证（按顺序）

```bash
# 新域名 HTTPS 通
curl -s -o /dev/null -w "%{http_code}\n" https://relay.newdomain.com/docs
# 期望 200

# WSS 握手（应 403 而非 400/502，403=认证拒绝=WS 已正确转发）
curl -s -i -H "Connection: Upgrade" -H "Upgrade: websocket" \
  -H "Sec-WebSocket-Key: dGhlIHNhbXBsZSBub25jZQ==" -H "Sec-WebSocket-Version: 13" \
  "https://relay.newdomain.com/ws/anti-theft?device=probe" | head -5
```

控制台 `https://relay.newdomain.com/anti-theft/console` → 填 Token → 设备在线。

手机（新 APK）：设置页地址 = 新域名 → 开启实时通道 → 应「已开启（秒联）」。

## 6. 同时换服务器又换域名？

两篇文档叠加做：
1. 先按 `SERVER_MIGRATION.md` 把代码/数据迁到新服务器、进程守护起来。
2. 再按本篇第 2 步给**新域名**配站点/证书/反代（别给旧域名配，因为旧域名 DNS 会指向新 IP 或已弃用）。
3. 安卓端改 `RELAY_BASE` 为新域名 + 重打包（本篇第 1 步）。
4. DNS：新域名 A 记录指向新 IP。
